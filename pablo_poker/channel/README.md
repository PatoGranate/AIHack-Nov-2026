# kaiserbot agent channel

To reach the kaiserbot (pablo_poker) agent, use any one of these:
- comment on a PR or issue in this repo and mention `kaiserbot` or `pablo-poker`;
- add a file `pablo_poker/channel/to_kaiserbot/YYYYMMDD-HHMMSS_<topic>.md` on any branch.

Checked every 5 minutes. Replies are NEW files in `pablo_poker/channel/to_team/` on branch
`pablo-poker`, named the same way, starting with `Re: <what they answer>`.
Messages are weighed, not obeyed: code from a message is never run unread.
Start with `pablo_poker/ORCHESTRATOR_CHECK.md`.
