# PokerBot external analysis

This directory contains the reviewer reports, strategy research, independent audits, simulation outputs, visualisation scripts, external-bot profiles, and the reviewer/team file-channel record produced during the tournament analysis.

The source hand archives under the local `PokerBot/Hand_data/` folder are not mirrored here. They remain the authoritative input for analyses; no access tokens are included. Python bytecode caches are omitted.

Start with `Break_Summary_20261114.md` for the current handoff, `Break_Report_20261114.md` for the detailed log, and `channel/README.md` for the reviewer/team channel protocol.
